# NestMatch roadmap

Version 1 deliberately focuses on one person making local, property-criteria-based decisions. It excludes authentication, multiple accounts, messaging, agent accounts, financing, offers, tours, alerts, AI neighborhood descriptions, demographic recommendations, scraping, a production database, subscriptions, and advertising.

## Version 1.1
- Improved filtering and search pagination
- Better photo support through authorized providers
- Additional live-data providers
- Map-based browsing
- Favorites notes and shortlist export
- Better property comparison
- Installable PWA support

## Version 2 — Couple Match
- Authentication, private profiles, and invite partner
- Independent swiping and shared matches
- “It’s a House Match!” celebration
- Agreement/disagreement insights and a shared shortlist
- Private comments, role-based access, and database security

## Version 3
- Real estate agent collaboration and tour-request workflow
- Search alerts, new-listing and price-change notifications
- Saved-search synchronization
- Advanced financial-planning inputs
- Authorized richer listing feeds and administrative monitoring
